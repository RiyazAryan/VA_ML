# Virgin Australia — Small ML Study

## Project Overview

This repository contains a small machine-learning study focused on Virgin Australia Airlines. The work is presented as two Jupyter notebooks that explore customer experience and time-based reporting related to the airline.

## Notebooks

- Customer experience analysis: [cus_exp/cus_exp.ipynb](cus_exp/cus_exp.ipynb)
- Time-based report and analysis: [time_report/time_report.ipynb](time_report/time_report.ipynb)

## Data

Data used for the analyses is loaded and described inside each notebook. If external CSV or other files are required, they are referenced from within the notebooks; please open the notebooks to see precise data sources and any preprocessing steps.

## Methods

- Exploratory data analysis (EDA)
- Feature engineering and cleaning
- Simple machine learning models (classification/regression) using scikit-learn
- Visualizations with matplotlib / seaborn

## Requirements

Recommended environment:

- Python 3.8 or newer
- Jupyter or JupyterLab
- pandas, numpy, scikit-learn, matplotlib, seaborn

Install common packages quickly:

```bash
python -m pip install --upgrade pip
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

## How to run

1. Install the requirements above.
2. Start Jupyter in the repository root:

```bash
jupyter notebook
```

3. Open and run the notebooks:
- [cus_exp/cus_exp.ipynb](cus_exp/cus_exp.ipynb)
- [time_report/time_report.ipynb](time_report/time_report.ipynb)

Run cells in order; notebooks include explanatory markdown and code cells to reproduce analyses and plots.

## Results

High-level findings and visualizations are summarized in the final sections of each notebook. For a concise summary, open the notebooks and review the conclusion sections and charts.
